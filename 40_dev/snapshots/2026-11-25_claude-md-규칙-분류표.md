## 3. 같이 해야 하는 것

1. **내릴 내용이 지침에 실제로 있는지 대조** — C 분류 5건과 A 분류의 세부(관찰로그 형식·friction·prompting·크기 상한)가 정본 문서에 빠짐없이 있는지 확인하고, 없으면 먼저 옮긴다. 옮기지 않고 지우면 규칙이 사라진다.
2. AGENTS.md 를 같은 내용으로 맞춘다(미러).
3. 다운스트림은 CLAUDE.md 의 관리 블록으로 받는다 — 전파는 활동 repo 만(ADR-007 D2).

## 4. 확인하지 못한 것

- 산문을 줄였을 때 준수율이 오르는지 내리는지는 측정한 적이 없다. §2 머리 주석이 인용한 권장(짧을수록 준수율↑)이 근거의 전부다.
- B 분류의 근거는 공개 요약의 repo 수뿐이다. 건수·비용은 비공개 상세에 있어 여기서 다시 세지 않았다.
- 16(부팅)은 세션 시작 훅으로 강제할 수 있는 후보다 — 그러면 A 로 옮길 수 있다. 이번 범위 밖.
