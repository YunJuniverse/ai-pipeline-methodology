# ADR-004: 자율 범위 확장 — 자동 착지(land)·실험 모드·자율주행

## Status

accepted

## Date

2026-08-07

## Context

방법론의 휴먼 게이트는 세 곳에서 마찰을 만들고 있었다.

1. **머지가 항상 사람 손에 있다.** `ship`이 push까지만 하고 멈춰, Class A 문서 변경조차 사람이 머지 버튼을 눌러야 했다. 그 사이 브랜치가 쌓이고(최장 8일·7개), Done 전이가 지연되며, 머지 후 CI 확인 단계가 아예 없었다 — 실제로 **CI `validate`가 #136·#137·#138 세 번 연속 main에서 red였는데 아무도 발견하지 못했다**(METH-132에서 복구).

2. **프로토타입과 운영이 같은 게이트 사다리를 쓴다.** 버릴 실험 코드의 스키마 변경에도 Class B 증거(근거·영향 범위·롤백 계획·리스크)를 요구하고, 가격 모델 시뮬레이션은 Class C로 구현이 중단된다. 대표가 "경영상의 제약이 프로토타입·서비스를 자유롭게 개발하는 데 제약이 된다"고 제기한 문제의 실체가 이것이다.

3. **장시간 자율 턴의 형식이 없다.** 지침 07이 예산·정지조건을 정의했지만 "8시간을 주면 그만큼 기획하고 루프를 돈다"는 실행 형태는 없었다. 지침 07 §5.2가 이미 규명했듯 wall-clock은 런타임이 강제하지 않는다(반복수·비용·권한범위 3개만 강제).

이 셋은 독립 요청으로 들어왔지만 하나의 계통이다: **자율을 넓히려면 그만큼 경계와 정지 조건을 기계로 박아야 한다.**

## Decision

### 1. `land` — 자동 착지 (METH-133)

`methodology.py land` 신설. `ship`이 *떠나보냄*이면 `land`는 *착지*다. 수거 캡슐 `invest-ops__2026-07-31_land-command-post-merge`의 설계를 채택했다.

단계: PR 식별 → **Class 판정** → **CI green 확인** → squash 머지 + 브랜치 삭제 → 기본 브랜치 동기화 → **maincheck**.

자동 머지 조건 (전부 만족해야 함, **fail-closed**):
- **Class A만.** 변경 경로에 Class B/C 트리거(마이그레이션·인증·과금·외부 API 계약·백그라운드 작업·CI 파이프라인·법무/정책)가 하나라도 걸리면 거부하고 사람을 부른다.
- **CI 실패 0건 + 진행 중 0건.** 체크 정보를 읽을 수 없으면 판정 불가로 보고 머지하지 않는다.
- **PR base가 기본 브랜치.** 스택-PR은 거부(METH-120).

판정 불가 = 진행하지 않음. 오탐(불필요한 사람 호출)은 싸고 미탐(무검토 머지)은 비싸다는 비대칭을 그대로 반영했다.

`ship --land`로 연결 실행. `--no-ci-check`는 명시적 우회로만 남긴다.

### 2. 실험 모드 — 지침 28 (METH-134)

Class B/C를 **제거하지 않고 공간적으로 유예**한다.

- **샌드박스 4조건** — 실데이터 없음 · 실사용자 없음 · 실결제 없음 · 대외 산출물 없음. 전부 만족할 때만 선언 가능. 경계는 repo가 아니라 작업 공간(브랜치·디렉터리)으로 긋는다.
- **안쪽**: Class B 전부 + Class C 중 기술 판단 + 테스트 선행 + ADR 의무 + 린트 래칫 해제.
- **그래도 유효**: 시크릿 취급 · 되돌리기 어려운 대외 행동 · 타인 자원 · 경계를 넓히는 결정 · 관찰 로그.
- **선언에 기한·범위·목적 필수.** 만료되면 자동으로 일반 모드.
- **졸업 게이트 7항** — 경계를 넘을 때 유예했던 게이트를 한 번에 정산(Class 재판정 → B 증거 소급 → C는 사람 승인 → 테스트 소급 → ADR → 래칫 복원 → 키·시드 정리). 올리는 부분에만 정산하고, 버린 것은 보고한다.

### 3. 자율주행 모드 — 지침 29 (METH-135)

- **시간은 예산의 단위이지 채워야 할 할당량이 아니다.** 1 사이클 ≈ 45~90분으로 환산해 사이클 수를 정하고, **기획이 소진되면 시간이 남아도 종료**한다.
- **P0 기획 선행** — 사이클 크기로 자른 작업 목록·의존 순서·이중 예산·정지 조건을 파일(`40_dev/snapshots/<date>_autopilot-plan.md`)로 남긴다. 컴팩션 생존 앵커.
- **4단계 루프**: 개발 → 검토(생성과 평가 분리) → QA(ground-truth만) → 신규작업 도출.
- **정지 조건 7종** — no-progress 2회 · 예산 초과 · Class B/C 도달 · 경계 이탈 요구 · 비가역 행동 · QA 연속 실패(재기획 신호) · 기획 소진.
- **사전 요구 4종** — 권한 사전 승인 · 샌드박스 경계 · 컴팩션 앵커 · ground-truth 판정 수단. 앞의 둘은 없으면 착수하지 않는다.

## Impact Scope

- `60_tools/methodology.py` — `cmd_land`, `_classify_change`, `CLASS_BC_PATTERNS`, `ship --land`
- `20_guides/28_실험_모드_샌드박스_경계.md`, `20_guides/29_자율주행_모드.md` (신설), `20_guides/README.md`
- `CLAUDE.md` §2 운영 규칙 — land·실험 모드 진입 규칙
- 백서 §5 휴먼 게이트 — 게이트 자체는 불변, *공간적 유예*와 *기계 대체* 경로가 추가됨
- shared 경로라 sync-all로 12개 다운스트림 전파

## Risk

- **자동 머지가 무검토 배포가 될 위험** → Class 판정 + CI green 이중 게이트, 둘 다 fail-closed. 판정 불가 시 진행 금지.
- **Class 판정이 경로 패턴 기반이라 우회 가능** → 패턴은 보수적으로(오탐 허용) 잡았고, 놓친 트리거는 friction으로 기록해 패턴을 넓힌다. 단 **넓히기 전에 신규 적중분 전수 재측정**(수거 캡슐 `measure-before-widening-a-guard`).
- **실험 모드의 경계 잠식** → 4조건은 협상 대상이 아니며, `land`의 Class 게이트가 실험 코드의 조용한 승격을 기계로 차단한다.
- **자율주행이 8시간 헛돌 위험** → 진척을 ground-truth로만 판정하고, no-progress 2회에서 정지.

## Alternatives Considered

- **전 클래스 자동 머지 (CI green만 확인)** — 기각. Class B/C 증거 요구가 사문화된다. 방금 CI red 3연속을 놓친 사고가 "기계 확인 없는 자동화"의 위험을 실증했다.
- **auto-merge 라벨 방식만 활성화** — 기존 `.github/workflows/methodology-auto-merge.yml`을 살리는 안. 기각(보조로만 유지) — repo 설정 `allow_auto_merge=false`에 의존하고, Class 판정·maincheck가 없어 착지 확인이 빠진다.
- **전면 게이트 해제(무경계 god 모드)** — 기각. invest-ops(조합원·금융 데이터)와 운영 중인 서비스가 같은 규칙을 받게 된다.
