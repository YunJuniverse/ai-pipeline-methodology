# 27. AI 영상 제작 지침

> AI 영상 생성(t2v·i2v)으로 마케팅·브랜드·제품 영상을 반복 제작하는 규칙. 상위 규범은 지침 25.
> 도구 지형은 2026-07 기준(Kling 3.0·Veo 3.1 양강, **Sora 소멸** — 모델 추상화의 실증). 리서치 정본: 스냅샷 §1.

---

## 1. 파이프라인 (사람 게이트는 지침 25 §5의 3위치)

```
① 스크립트(사람) → ② 샷리스트 락(게이트 ①) → ③ 레퍼런스 캐논 제작
→ ④ 저가 1차 패스 → ⑤ 풀 렌더 승인(게이트 ②) → ⑥ 편집·합성 → ⑦ 브랜드 QA(게이트 ③)
```

- 최종 비주얼이 AI여도 **스크립트·러프 스토리보드는 사람 먼저**(성공 사례 공통).
- 샷은 모델 클립 한계에 맞춰 **4~8초 단위로 분해**하고, 생성 전에 씬·프레이밍·타이밍·보이스·온스크린 텍스트를 락.
- 재시도 3회 상한 — 초과 시 프롬프트가 아니라 샷 분해를 재검토(지침 25 §4).

## 2. 샷 스펙 파일 (재현성의 단위)

샷당 1개 YAML/MD를 repo에 커밋:

```yaml
shot_id: S03
duration: 6            # 초
framing: close-up      # wide|medium|close-up|...
camera: slow dolly-in
lighting: soft morning light
action: 캐릭터가 제품을 집어 들고 미소
dialogue_sfx: 'SFX: 잔잔한 카페 소음'
reference_assets: [assets/canon/char-a-front.png, assets/canon/char-a-34.png]
model: <role:i2v>      # 역할 참조 — 실제 모델은 설정에서
seed: 12345
prompt_version: v3
status: draft          # draft|pass1|approved|final
```

## 3. 프롬프트·일관성 기법

- **프롬프트 5부 구조**: `[촬영기법] + [피사체] + [행동] + [맥락/환경] + [스타일·무드]`. 카메라(dolly/tracking/crane/POV)·구도(wide/low angle)·렌즈(shallow DOF)·조명(low-key/noir) 어휘를 명시.
- **레퍼런스 주입이 1급 기법**(시드보다 신뢰): 캐릭터·제품당 정면·¾·프로필·클로즈업 3~5장 캐논 세트를 `assets/canon/`에 두고 모든 i2v에 주입.
- **클립 연결**: First/Last Frame — 시작·끝 프레임 이미지를 먼저 확정하고 사이를 애니메이트(hand-over-hand 체이닝).
- 오디오: 대사는 따옴표, `SFX:`/`Ambient noise:` 접두, 타임스탬프(`[00:00-00:02]`)로 단일 생성 내 페이싱.
- 네거티브는 부정문 대신 원하는 상태 서술("no buildings" ✗ → "a desolate landscape with no buildings or roads" ✓).
- **프레임 내 텍스트·로고는 생성 금지** — 편집 단계 오버레이(지침 25 §7).

## 4. 비용 관리

- `예산 = Σ(샷 길이초 × 단가/s × 시도계수)` — 시도계수는 실측 채택률로 갱신. 벤치마크(2026-07): 저가 티어 ~$0.05/s · 중가 ~$0.10/s · 프리미엄 ~$0.40/s · 배치 -50%.
- 1차 패스는 저가 모델/저해상도로 모션·구도만 확인 — 풀 렌더는 통과 샷만.
- 무료 티어 산출물 상업 사용 금지·크레딧 대량 선구매 금지(지침 25 §1·§9).

## 5. QA 체크리스트 (게이트 ③, 퍼블리시 직전)

- [ ] 손·얼굴·반사·그림자 아티팩트 / 모핑·워핑 프레임
- [ ] 프레임 내 우연 생성된 텍스트·로고·패키지 철자
- [ ] 클립 간 색온도 일치 / 립싱크
- [ ] 의도치 않은 타사 로고·실존 인물(발견 시 폐기 — 지침 25 §9)
- [ ] 브랜드 요소(제품·얼굴·로고) 형태 변형 → 무조건 리테이크
- [ ] 해상도 플랫폼 최소치(1080p) / AI 생성 표시(지침 25 §9) / 사실 주장·권리 확인
