# 26. AI 이미지·캐릭터 에셋 제작 지침

> AI 이미지 생성으로 캐릭터 IP·마케팅·제품 에셋을 반복 제작하는 규칙. 상위 규범은 지침 25(모델 추상화·provenance·게이트 3위치·법무는 그쪽이 정본).
> 도구 지형은 2026-07 기준 — 분기 재검증. 리서치 정본: `40_dev/snapshots/2026-07-29_AI디자인-방법론-리서치.md` §2.

## 1. 도구는 용도별 고정 (역할 매트릭스)

| 역할 | 1순위 (2026-07) | 비고 |
|---|---|---|
| 지시 정확도·복잡 구성 | GPT Image 2 | 텍스트 렌더 ~99%(한국어 포함), 고품질 $0.21/장 |
| 캐릭터 반복·다인 일관성 | Nano Banana Pro | 레퍼런스 8장·5인 유지, SynthID 자동(표시 의무 유리) |

## 2. 캐릭터 일관성 사다리 (비용 오름차순)

1. **정본 캐릭터 시트** — 캐릭터당 1개: 정면·측면·후면·¾ + 특징 라벨(이목구비·비율·의상 디테일). **사람 승인 후 동결**(게이트 ①). 모든 생성의 전제.
2. **레퍼런스 주입** — 일상 생성의 기본기: 정본 시트를 매 생성에 첨부. 현세대에서 "대부분 용도의 일관성은 해결" 수준.
3. **LoRA 승급** — 캐릭터가 시리즈화(컷 수십 장↑·굿즈 대량 전개)되면 파인튜닝: 캡션 포함 15~20장 학습, 회당 ~$2~8. 장기 일관성 최고.
4. **시드**는 재현 기록용 보조 — 단독 일관성 수단으로 쓰지 않는다.

## 3. 표준 파이프라인

```
브리프 → 프롬프트(git 버전) → 후보 N장 생성 → 1차 스크리닝
→ 인페인팅 국소 수정(전체 재생성 금지) → 클린 베이스 승인(게이트 ②)
→ 업스케일 → 배경 제거·포맷 → 검수 → approved/ 이동 → 납품(게이트 ③)
```

- **업스케일은 클린 베이스 승인 후에만** — 결함 있는 이미지를 업스케일하면 결함도 커진다.
- 대량 배치는 Batch API(-50%). 생성:채택 비율 추적(지침 25 §4).

## 4. 검수 2단 + 인쇄 크기

- **1차(생성 직후)**: 손·손가락·치아·귀 / 이미지 내 텍스트 확대 검수 / 물체 경계·배경 융합 / 조명 일관성 / **정본 시트 대조**(이목구비·비율·의상).
- **2차(업스케일 후)**: 헤일로·아티팩트 재검 / 타사 로고·워터마크·유명 IP 유사성 스크리닝(발견 시 수정 없이 폐기 — 지침 25 §9).
- **굿즈·인쇄물은 실제 인쇄 크기로 확대 검수** — 화면 검수만으로는 인쇄 사고(지침 23 §2 "최대 표시 크기" 인스턴스).

## 5. 에셋 관리

- 명명: `<프로젝트>_<에셋ID>_<용도>_<v#>_<상태(draft|approved)>` — "final2.png" 금지.
- 디렉터리: 정본은 `assets/canon/`, 승인본만 `approved/` — 미승인·후보와 물리 분리.
- 장당 provenance 기록(모델·프롬프트v·시드·레퍼런스·후처리·승인 상태) — 지침 25 §3(저작권 증빙 겸용). 최소 구현은 스프레드시트/CSV 1개.
- 중간 산출물(원본 생성물)은 커밋 또는 백업 — scratchpad는 세션 재개 시 소실된다.
