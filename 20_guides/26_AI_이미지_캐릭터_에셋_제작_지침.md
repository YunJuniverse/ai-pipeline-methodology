# 26. AI 이미지·캐릭터 에셋 제작 지침

## 1. 도구는 용도별 고정 (역할 매트릭스)

> **이 절은 역할·원칙·라이선스 등급만 담는다.** 현 분기의 모델명·참조 장수·단가는 `20_guides/_data/2026-Q3_design-tool-landscape.md` 에 있다(분기마다 새 파일, methodology:ADR-005). 모델은 분기 단위로 바뀌고(지침 25 §1), 수치가 지침에 있으면 틀린 수치가 지침의 권위를 얻는다.

| 역할 | 선택 기준 | 라이선스·면책 요구 |
|---|---|---|
| 지시 정확도·복잡 구성 | 텍스트 렌더(한국어 포함)·지시 추종 | 상업 이용 가능 등급 |
| 캐릭터 반복·다인 일관성 | **다중 참조 편집** — 참조 장수 중 *캐릭터 일관성용* 장수를 본다(총 참조 장수와 다르다) | 외부 노출이면 면책 경로 우선 |
| 대량·장편·스타일 고정 | LoRA 학습 가능한 오픈 웨이트 | **상업 가능 라이선스의 웨이트만**(아래 「라이선스 읽기」) |
| 텍스트·로고·타이포 | 벡터(SVG) 출력 여부 | 무료 티어 = 소유권 없음인 도구가 있다 — 유료 플랜 확인 |
| 보수적 납품(면책 필요) | 제조사 IP 면책 | **면책이 있는 경로는 제조사 자사 모델·클라우드 면책 둘뿐** — 클라이언트·기업 브랜드용 |
| 소송 진행 중인 모델 | **IP 정본 제작 금지(유예)** | 종결 후 재평가 |

### 1b. 라이선스 읽기 (methodology:ADR-005 — 2026-09-21 사람 승인)

- **출력 조항과 모델 구동 조항을 따로 읽는다.** 비상업 라이선스 오픈 웨이트는 «출력은 상업 사용 가능»이라고 쓰여 있어도, **업무·수익 활동에서 모델을 구동하는 것 자체가 라이선스 밖**일 수 있다. 실례: FLUX.2 [dev]·[klein 9B] 는 비상업 라이선스 — 상업 산출물은 [klein 4B](Apache-2.0)·BFL API·상업 라이선스 경로로. (v1 의 «dev 웨이트는 출력만 상업 OK» 는 이 구분을 빠뜨린 문장이었다.)
- **적용 지역 제외 조항을 확인한다.** 오픈 모델 라이선스에는 특정 국가를 적용 대상에서 빼는 조항이 있다 — 그 나라의 법인·사용자는 그 라이선스로 쓸 수 없다. 한국이 제외된 실례가 데이터 파일에 있다.
- **출처 등급을 본다.** 참조 장수·단가를 루머·3자 블로그 출처로 채택하지 않는다. 데이터 파일은 행마다 `1차`(제조사 문서·원문) / `인용`(리서치 출처)을 표시한다.
- 법률 자문이 아니다 — 상업 사용 결정 전에는 원문과 법무 확인.

## 2. 캐릭터 일관성 사다리 (비용 오름차순)

1. **정본 캐릭터 시트** — 캐릭터당 1개: 정면·측면·후면·¾ + 특징 라벨(이목구비·비율·의상 디테일). **사람 승인 후 동결**(게이트 ①). 모든 생성의 전제.
2. **레퍼런스 주입** — 일상 생성의 기본기: 정본 시트를 매 생성에 첨부. 현세대 생성 모델이 «다중 참조 편집»으로 수렴해(2026-Q3) 파인튜닝 없이 대부분 용도의 일관성이 해결된다. 참조 장수는 모델마다 다르고 **캐릭터 일관성용 한도가 총 한도보다 작다** — 데이터 파일 참조.
3. **LoRA 승급** — 캐릭터가 시리즈화(컷 수십 장↑·굿즈 대량 전개)되면 파인튜닝: 캡션 포함 15~20장 학습, 회당 ~$2~8. 장기 일관성 최고.
4. **시드**는 재현 기록용 보조 — 단독 일관성 수단으로 쓰지 않는다.

## 3. 표준 파이프라인

```
브리프 → 프롬프트(git 버전) → 후보 N장 생성 → 1차 스크리닝
→ 인페인팅 국소 수정(전체 재생성 금지) → 클린 베이스 승인(게이트 ②)
→ 업스케일 → 배경 제거·포맷 → 검수 → approved/ 이동 → 납품(게이트 ③)
```

- **업스케일은 클린 베이스 승인 후에만** — 결함 있는 이미지를 업스케일하면 결함도 커진다.
- 대량 배치는 Batch API(-50%). 생성:채택 비율 추적(지침 25 §4).

## 4. 검수 2단 + 인쇄 크기

- **1차(생성 직후)**: 손·손가락·치아·귀 / 이미지 내 텍스트 확대 검수 / 물체 경계·배경 융합 / 조명 일관성 / **정본 시트 대조**(이목구비·비율·의상).
- **2차(업스케일 후)**: 헤일로·아티팩트 재검 / 타사 로고·워터마크·유명 IP 유사성 스크리닝(발견 시 수정 없이 폐기 — 지침 25 §9).
- **굿즈·인쇄물은 실제 인쇄 크기로 확대 검수** — 화면 검수만으로는 인쇄 사고(지침 23 §2 "최대 표시 크기" 인스턴스).

## 5. 에셋 관리

- 명명: `<프로젝트>_<에셋ID>_<용도>_<v#>_<상태(draft|approved)>` — "final2.png" 금지.
- 디렉터리: 정본은 `assets/canon/`, 승인본만 `approved/` — 미승인·후보와 물리 분리.
- 장당 provenance 기록(모델·프롬프트v·시드·레퍼런스·후처리·승인 상태) — 지침 25 §3(저작권 증빙 겸용). 최소 구현은 스프레드시트/CSV 1개.
- 중간 산출물(원본 생성물)은 커밋 또는 백업 — scratchpad는 세션 재개 시 소실된다.
