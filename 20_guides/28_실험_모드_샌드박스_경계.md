# 28. 실험 모드 — 샌드박스 경계와 졸업 게이트

> 프로토타입을 **제약 없이** 만들기 위한 모드. 게이트를 없애는 게 아니라 **경계 안쪽에서 유예하고 경계에서 한 번에 정산**한다.
> 위상: 백서 §5 휴먼 게이트의 *공간적 예외*. 지침 07(자율 예산)이 "언제 멈추나"의 시간 규율이라면, 이 지침은 "어디서는 안 멈춰도 되나"의 공간 규율.
> 핵심 가치: **경계가 있어야 자유가 있다. 경계 없는 자유는 곧 전면 동결로 되돌아온다.**

---

## 1. 왜

방법론의 Class B/C 게이트는 *운영 중인 서비스*를 지키려고 만들어졌다. 그런데 프로토타입에도 똑같이 걸린다:

- 실험용 스키마 한 번 바꾸려면 → Class B → 근거·영향 범위·롤백 계획·리스크를 PR에 써야 한다
- 인증 흐름을 시험 삼아 갈아엎으려면 → Class B
- 가격 모델을 여러 개 시뮬레이션해 보려면 → Class C → **구현 중단 + ADR + 사람 승인 대기**

셋 다 옳은 규칙이다 — *운영에서는*. 프로토타입에서는 이게 그냥 마찰이다. 버릴 코드에 롤백 계획을 쓰고, 아무도 안 쓰는 DB의 스키마 변경에 승인을 기다린다.

**진단: 규칙이 많은 게 문제가 아니라, 프로토타입과 운영이 같은 게이트 사다리를 쓰는 게 문제다.** 그래서 해법은 게이트 제거가 아니라 사다리 분리다.

## 2. 샌드박스 경계 — 4조건 전부 만족해야 한다

어떤 작업 공간이 **아래 4개를 전부** 만족할 때만 실험 모드를 선언할 수 있다. 하나라도 어긋나면 일반 모드다.

| 조건 | 의미 | 위반 예 |
|---|---|---|
| **실데이터 없음** | 프로덕션 DB·실고객 레코드·개인정보·금융 데이터에 읽기조차 붙지 않는다. 시드/합성 데이터만. | invest-ops 조합원 데이터를 프로토타입에 연결 |
| **실사용자 없음** | 나 말고 아무도 쓰지 않는다. 외부 접근 가능한 URL이 없거나 인증 뒤에 있다. | 프로토타입을 고객에게 링크로 공유 |
| **실결제 없음** | 실제 돈이 움직이지 않는다. 결제 게이트웨이는 테스트 키만. | 라이브 결제 키를 실험 브랜치에 |
| **대외 산출물 없음** | 이 공간의 결과물이 그대로 외부에 나가지 않는다(브랜드 카피·공개 페이지·IR 문서·고객 발송물). | 실험으로 만든 카피를 랜딩에 그대로 |

> 경계는 **repo가 아니라 작업 공간**으로 긋는다. 운영 서비스 repo 안에서도 `experiments/` 디렉터리나 `lab/*` 브랜치는 샌드박스가 될 수 있고, 반대로 프로토타입 repo라도 실고객이 붙는 순간 경계 밖이다.

## 3. 경계 안에서 해제되는 것 / 그래도 유효한 것

### 해제 (실험 모드에서 게이트 없이 진행)

- **Class B 전부** — 스키마·마이그레이션, 외부 API 계약 변경, 인증·인가 변경, 파괴적 데이터 변경, 백그라운드 작업 도입
- **Class C 중 기술 판단** — 가격·정책 *시뮬레이션*, 아키텍처 전면 교체, 스택 교체
- **테스트 선행 의무**(지침 07·CLAUDE.md §7) — 버릴 코드에 테스트를 먼저 쓰지 않아도 된다
- **ADR 의무** — 실험 중 결정은 기록하지 않아도 된다(졸업 시점에 한 번에 정리)
- **린트 래칫·커버리지 게이트** — 경고로 낮춘다

### 그래도 유효 (해제되지 않는다)

- **시크릿·자격증명 취급** — 실험이든 아니든 `.env`·키·토큰은 커밋 금지. `ship` sensitive 검사는 그대로.
- **되돌리기 어려운 대외 행동** — 발송·공개·과금·삭제는 샌드박스 밖 행위다. 지침 07 §5.5가 그대로 적용.
- **타인의 자원** — 다른 프로젝트의 프로세스·포트·데이터를 건드리지 않는다. 규범 정본은 **지침 07 §2 부작용 범위 봉쇄**(실험 모드 전용이 아니라 일반 자율 규율로 승급됨).
- **경계 자체를 넓히는 결정** — "실데이터를 잠깐만 붙여보자"는 실험이 아니라 경계 이동이다. 사람 승인.
- **관찰 로그** — 실험이야말로 마찰의 원천이다. `observe`는 계속 남긴다(오히려 더 가치 있다).

> 요약: **안쪽은 기술적 자유, 경계는 여전히 단단하다.** 실험 모드는 "무엇을 만들어도 되는가"를 열지, "무엇을 세상에 내보내도 되는가"를 열지 않는다.

## 4. 선언 — 시간·범위 박스

실험 모드는 **선언해야 켜지고, 선언에 만료가 있어야 한다**. 조용히 켜진 실험 모드는 그냥 게이트 없는 운영이다.

```markdown
<!-- CLAUDE.md §1 또는 HANDOFF.md 상단 -->
- **Lab**: `lab/pricing-sim` 브랜치 · ~2026-08-14 · 목적: 3개 가격 모델 시뮬레이션
  - 경계 확인: 실데이터 ✗ / 실사용자 ✗ / 실결제 ✗(테스트 키) / 대외산출물 ✗
```

- **범위**: 브랜치·디렉터리·repo 중 무엇인지 명시. "이 프로젝트 전체"는 범위가 아니다.
- **기한**: 날짜를 박는다. 지나면 자동으로 일반 모드로 돌아간다 — 연장은 재선언(지침 07 §5.7 정신).
- **목적**: 무엇을 알아내려는 실험인지. 목적이 달성되면 기한 전이라도 졸업 판정을 한다.

## 5. 졸업 게이트 — 경계를 넘을 때 한 번에 정산

실험 결과물을 운영으로 올릴 때(= 4조건 중 하나라도 깨질 때), **유예했던 게이트를 전부 그 시점에 정산한다**. 이게 실험 모드가 안전한 유일한 이유다.

정산 목록:

1. **Class 재판정** — 실험 중 건드린 것 중 Class B/C에 해당하는 것을 전수 나열한다(스키마·인증·과금·외부 계약·백그라운드 작업).
2. **Class B 증거 소급 작성** — 각각에 대해 결정 근거·영향 범위·롤백 계획·리스크. 실험 중엔 안 써도 됐지만 여기서는 쓴다.
3. **Class C는 멈추고 사람 승인** — 가격·정책·브랜드·공개 릴리스는 여기서 정식 게이트를 통과한다.
4. **테스트 소급** — 살아남는 로직에 테스트를 붙인다. 버려지는 코드에는 안 붙인다.
5. **ADR 1건** — "왜 이 방향인가"를 실험 결과로 쓴다. 실험은 ADR의 가장 좋은 재료다(대안을 실제로 만들어 봤으므로).
6. **린트 래칫 복원** — 경고로 낮췄던 것을 다시 차단으로.
7. **시크릿·테스트 키 정리** — 테스트 키·시드 데이터·목 서버가 운영 경로에 남지 않았는지 확인.

> **부분 졸업이 정상이다.** 실험 결과의 90%는 버리고 10%만 올린다. 정산은 *올리는 10%*에 대해서만 한다 — 버릴 것에 롤백 계획을 쓰지 않는다. 무엇을 버렸는지는 보고한다(침묵 절단 금지, 지침 07 §2).

## 6. 실패 모드 (이 지침이 막으려는 것)

| 실패 | 증상 | 방지 |
|---|---|---|
| **경계 잠식** | "잠깐만 실데이터 붙여서 확인" → 그대로 굳음 | 4조건은 판정이지 협상이 아니다. 붙이는 순간 일반 모드. |
| **영구 실험** | lab 브랜치가 6개월째 살아 있고 실사용자가 붙음 | 기한 필수 + 만료 시 자동 일반 모드 |
| **졸업 없는 승격** | 실험 코드가 조용히 main으로 | `land`의 Class B/C 게이트가 기계로 차단(METH-133) — 실험 모드는 `land` 자동 머지를 열어주지 않는다 |
| **정산 누락** | 올렸는데 Class B 증거가 없음 | 졸업 게이트 7항을 PR 본문 체크리스트로 |

## 7. 다른 지침과의 경계

- **백서 §5 / CLAUDE.md §3**: Class 규칙 자체는 안 바뀐다. 이 지침은 *어디서 유예되는가*만 정의한다.
- **지침 07 (자율 예산)**: 시간·compute 규율. 실험 모드에서도 예산 선언·no-progress 정지는 그대로.
- **지침 29 (자율주행)**: 자율주행 루프가 Class B/C에서 멈추지 않으려면 샌드박스 안이어야 한다 — 이 지침이 **선결 조건**이다.
- **지침 24 (착수 게이트)**: 실험도 착수 게이트는 통과한다. 정본·전제 확인은 실험이라고 면제되지 않는다(잘못된 전제 위의 실험은 답을 못 준다).
