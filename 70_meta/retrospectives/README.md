# 70_meta/retrospectives/ — 분기 회고

> 분기마다 1회. 백서 §7 지표 대비 실측 + 다음 분기 우선순위 결정.
> 자가발전 루프의 *사람 측 게이트*.

## 파일명

`YYYY-QN_<slug>.md` (예: `2026-Q2_methodology-review.md`)

## 지표 소스 (회고 직전 실행)

회고 §1 지표는 아래를 실행해 **실측치**로 채운다:

```
python3 60_tools/methodology.py thinktank
```

출력 `## 지표 (Metrics)` 섹션(관찰 건수·기간·케이던스·task_type 분포·마찰/재적중/승급 후보 수)을 §1에 반영한다. **thinktank는 자동 승급하지 않는다** — 승급 후보만 마킹하고, 승급은 사람이 PR로(백서 §8-2). thinktank는 회고의 지표 피더이자 후보 리스트일 뿐이다.

## 표준 섹션

1. **지표 측정** — 백서 §7-1~§7-4 각 지표 실측치 + 이전 회차 대비 (thinktank 출력 기반)
2. **무엇이 효과적이었나** — 측정 기반, 추측 금지
3. **무엇이 부패했나** — Catalog 적중률 저하, 자동기록 누락 등
4. **다음 분기 우선순위** — 3건 이내, TODO ID 부여
5. **백서 변경 제안** — 있으면 RFC 신설 트리거

## 운영

- 회고는 *지표가 충분히 누적된 후*에만 의미 — 관찰 100건+ / Catalog 5+ 권장
- 측정 불가능한 회고는 *현 회고가 부패한 신호* → 다음 분기 *지표 인프라*가 1순위
