# 2026-Q3 — 방법론 첫 분기 회고

> 백서 §9가 지정한 "8주 이후 ROI 검증 + 분기 백서-현실 정렬 회고"의 **첫 발화**.
> ~9주 초과 상태였고, 무게 감사·SOTA 평가가 그 초과를 지목해 촉발됨.

## 1. 지표 측정 (백서 §7 대비)

**⚠️ 정직 모드: 지표 인프라가 임계치 미달이다.** README 권장 = 관찰 100건+ / active Catalog 5+. 실측:

백서 §7 정량지표(부팅 시간·인계 성공률·벤더 잠금 점수·모델 다양성)는 **대부분 미계측**. 관찰 로그에 friction/cost_minutes 필드는 있으나 집계 파이프라인(thinktank)이 휴면이라 추세를 못 낸다.

**→ README 자체 규칙 적용:** *"측정 불가능한 회고는 현 회고가 부패한 신호 → 다음 분기 지표 인프라가 1순위."* 이 회고는 그 신호다. (§4-P1 참조)

정성 인계 실측(이번 분기): 세션 간 인계는 checkpoint·HANDOFF로 실작동했고, 이번 세션은 **서브에이전트 워크플로우로 토론·감사·리서치**를 격리 실행해 근거 있는 결정을 산출(정성적으로 인계·이식성 원칙이 작동). 단 정량 부팅 시간·인계 성공률은 미측정.

## 2. 무엇이 효과적이었나 (측정 기반)

- **경험적 루프가 실제로 1회전 완주.** L1 관찰 → 실세계 반복(gamblescan) → N≥2 → active `C-001` 승급 → skeleton bake-in → 하류 전파(METH-049·050). 자가발전 루프의 end-to-end 증명 1건 확보.
- **이식성·가드레일 원칙 작동.** 벤더 중립(CLAUDE/AGENTS 이중), fail-closed 가드레일(지침 19·20)이 하류에서 실제 위반 검출(gamblescan 회색 32건).
- **하네스로서의 서브에이전트 토론.** 이번 분기 신규: guide 05 격상 판정·무게 감사·SOTA 평가를 격리 서브에이전트(입론→반론→심판, 4렌즈→검증→심판)로 실행 → 인상비평 아닌 파일 근거 결정. (SOTA 평가상 harness/context engineering과 정합)

## 3. 무엇이 부패했나

- **L3 thinktank 휴면.** 자동 마이닝 산출물이 2026-05-14 이후 재생성 0인데 관찰은 41건 누적. 승급 3건(C-001·MC-001·MC-002) 전부 수동 PR. → **문서(자가발전 자동 루프 서사)와 현실(수동 승급)의 부패** (백서 §9 "백서 자체의 부패" 확증).
- **ROI 게이트 ~9주 초과.** 이 회고가 그 부패의 결과이자 시정.
- **온보딩 밴드 중복 + 드리프트.** Change Class 전문이 6문서 재서술, CLAUDE↔AGENTS L39 콘텐츠 드리프트(무게 감사 확증).
- **이번 세션 프로세스 사고 2건:**
  - **스택 PR 고아화** — RFC-002(#42)가 이미 머지된 base 브랜치로 머지돼 main 미도달. gh는 "MERGED" 표시하나 main에 부재 → METH-053에서 복구. **MP-003으로 캡처**(재발 시 N≥2 → MC 승급).
  - **guide 04 번호 충돌** — 상류 신규 04가 다운스트림 커스텀 04와 doc_id 충돌 → METH-053에서 05 리넘버 + guide 02 §8 예약범위(상류 00–89/다운스트림 90–99)로 시정.

## 부록 — 이번 회고의 메타 교훈

첫 회고가 "지표 미달"로 나온 것 자체가 방법론의 정직성 신호다. 백서 §9는 이를 예견했고("1인 사용 한계효용"), README는 대응까지 규정했다("지표 인프라 1순위"). **방법론이 자기 부패를 자기 규칙으로 잡아냈다** — 이 회고의 존재가 §9 게이트가 (늦었지만) 작동함을 증명한다. 다음 회고(2026-Q4)의 성공 기준: **P1 지표 인프라가 서서 §7 지표를 실제 수치로 채우는 것.**
