# KPI 단위경제 트리 (Unit Economics) — 템플릿

> 용도: 수익모델을 매출→이익 계층으로 분해. 지침 `20_guides/10_사업기획서_작성_지침.md` §19.3 참조.

## 계층 정의 (위=매출, 아래=이익)

| 지표 | 정의 | 공식 |
|---|---|---|
| **GMV** | 거래 총액 | 결제금액 − 취소금액 |
| **Net Revenue** | 순매출(마진) | GMV × 수수료율 |
| **Gross Margin** | 매출이익 | Net Revenue − 고정비(급여·임대·외주·기타) |
| **Contribution Margin** | 기여이익 | Gross Margin − 변동비(결제수수료·CS·서버·세금 등) |

|---|---|---|---|---|---|---|---|---|---|

## 고정비·변동비 분해

| 구분 | 항목 | 월 추정액 |
|---|---|---|
| 고정비 | 급여(+퇴직·상여·복리후생) / 임대료 / 외주 / 기타 | |
| 변동비 | 결제수수료 / CS / 서버 / 세금·공과 등 | |

**원칙**: 사업기획서의 "뒷단"(수익·KPI)은 형용사가 아니라 *수치*로. 시장규모(TAM/SAM/SOM)·객단가와 함께 채워야 완결.
