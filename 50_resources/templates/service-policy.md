# 서비스 정책서 (Service Policy) — 템플릿

> 용도: 반복 행위에서 발견한 규칙(서비스의 "법")을 2-시트로 관리. 지침 `20_guides/11_서비스기획서_작성_지침.md` §19.4 참조.

## 시트 1 — 정책 관리대장

| Ver | 정책구분 | 주관부서 | 담당 | 최종수정일 |
|---|---|---|---|---|
| v1.01 | (사이트이용/회원·인증/결제취소·환불/포인트·쿠폰/탈퇴 …) | | | |

## 시트 2 — 정책 상세 (정책구분마다 1매)

| 분류 | 문의내용 | 상담안내(단계 서술) | 오류 및 개선사항 |
|---|---|---|---|
| | | (예: 로그인 - 나의정보 - 회원탈퇴) | |

**작성 패턴**(조건문): "반복되는 [무엇을] → 어떻게 [해야 한다] → [새 문제]". 근거·예외는 불릿으로 (해당/비해당 케이스 구분). 내부(개발 반영)/외부(운영 반영) 분리. 출력 = 행동가이드(OFF=수동) vs 해결책(ON=자동화).
