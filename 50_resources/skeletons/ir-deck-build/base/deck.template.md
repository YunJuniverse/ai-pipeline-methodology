> 지침 22 §2. **이 md가 덱의 단일 정본(SSOT)이다.** 스토리라인·슬라이드 텍스트는 여기서만 편집하고 리빌드한다.
> pptx/pdf는 파생물 — 텍스트를 pptx에서 직접 고치지 않는다(다음 빌드에 덮인다).
> 콘텐츠(이 파일)를 먼저 사람 승인으로 닫은 뒤에 디자인(테마 후보)을 시작한다.

## 콘텐츠 2층 (디자인보다 먼저)

**① 스토리라인 (덱 레벨, P1)** — 어떤 슬라이드가 무슨 순서로. [헤드라인]만 이어읽어 논증이 성립해야 한다(타이틀 테스트). Sequoia 10항목을 척추로, 국내 리딩덱 20~30장.

```
S01 표지 → S02 시장 기회 → S03 문제 → S04 솔루션 → S05 시장(TAM/SAM/SOM)
→ S06 Why Now → S07 경쟁 → S08 제품 → S09 BM → S10 재무 → S11 팀 → S12 클로징
→ Appendix(전표·부문 실적·핵심인력·Q&A·Sources)
```

**② 슬라이드 내 텍스트 구조화 (슬라이드 레벨, P2)** — 각 슬라이드의 정보 위계. 아래 4필드 고정.
