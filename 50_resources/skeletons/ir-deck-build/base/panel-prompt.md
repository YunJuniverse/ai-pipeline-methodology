# 멀티에이전트 실사 패널 프롬프트 (P4 검증)

> 지침 22 §4.2. 렌더된 덱 PDF를 4개 렌즈가 **각자 통독**하고 결함을 지지 패널 수로 랭킹.
> 서브에이전트 오케스트레이션은 지침 08(컨텍스트 격리 + 적대적 검증)을 따른다 — 4개를 팬아웃하고 요약만 회수.

## 공통 지시 (각 에이전트에 배포)
```
대상: [덱 PDF 경로] 전 N장을 직접 통독하라. 지어내기 금지 — 덱에 실제로 있는 근거만.
출력: ①한 줄 판정 ②결함 목록(슬라이드 번호·심각도[치명/高/中]·자력가능🟢 or 대표·재무확인🔴)
      ③이 렌즈가 인정한 강점 ④(악마·실사만) 실사 첫 질문 3~5개
```

## 렌즈 4종
1. **VC 시니어 심사역** — 투자 논리 사슬. "시장 증명 N장 vs 가격 증명 M장"의 균형을 본다. 역피라미드(시장 과잉·가격 0장) 탐지.
2. **실사 애널리스트** — 수치 정합성만. 각주↔헤드라인 일치, 부문 합산 시 드러나는 역성장·GMV/인식매출·유효세율·인원 모순. 방어력 N/10 점수.
3. **피치덱 내러티브 전문가** — 흐름·이음새·중복. "두 벌 덱이 이어붙었나", 중복 수치 3회+(파이프라인 부풀리기 시그널), 재배열·병합안.
4. **악마의 변호인** — 반박 시뮬레이션. 자충돌(같은 덱 안에서 모순되는 두 수치), 가장 강한 카드를 약한 카드 뒤에 숨긴 구조, 프레임 급소.

## 종합 (오케스트레이터)
- 결함을 **지지 패널 수** 순으로 랭킹(4/4 = 합의 치명).
- 🟢 자력 즉시 / 🔴 대표·재무 확인으로 분리 → 액션 우선순위.
- 🔴(밸류·투자조건·수치 확정)는 Class C — AI는 틀·문구만 개선, 수치는 확인 대기(§5).
